# 🚦 Slotcar Startlight "Bären(n)keller" - 3D CAD Models

## 🏎️ Project Overview

Custom 3D CAD models and mechanical design for the self-developed Slotcar Startlight "Bären(n)keller" for the CARRERA® Digital 124/132 racing system.

This repository contains all CAD models and 3D-printable components required to build the complete start light assembly, including the bridge, support structure, mounting components, cable routing features, and custom connectors.

The design was developed as part of a complete embedded system consisting of:

- 🔌 Custom electronics
- ⚙️ Embedded firmware
- 📐 PCB design
- 🖨️ 3D CAD models
- 📚 Technical documentation

## 🧠 Mechanical Design Highlights

### 🌉 Modular Bridge System

The start light bridge consists of a scalable construction concept.

Features:

- Two-lane base configuration
- Optional extension segments
- Support for pit lane installations
- Scalable width for larger track layouts

---

### 🏗️ Integrated Electronics Housing

The enclosure was specifically designed around the electronics assembly.

Features include:

- Dedicated PCB mounting system
- LED alignment and positioning
- Integrated cable routing
- Easy assembly and maintenance access

---

### 🔩 Flexible Mounting System

Several mounting options are available:

- Track-mounted feet
- Control Unit mounting
- Screw-mounted installation
- Modular support columns

This allows the start light to be adapted to different track layouts and racing environments.

---

### 🖨️ Additive Manufacturing

The components were designed for FDM 3D printing.

Design considerations include:

- Minimal support structures
- Easy assembly
- Replaceable parts
- Modular extensions
- Practical manufacturing

## 📖 Project Background

The project originated from a private CARRERA® Digital 132 racing track installation.

The original CARRERA® Startlight could not span a track consisting of two racing lanes plus pit lane and offered only limited indication functionality.

As part of the overall development, a custom mechanical system was created to provide:

- Stable mounting
- Expandability
- Easy maintenance
- Professional appearance
- Seamless integration of electronics and cabling

The design has successfully been used for several years in practical operation.
